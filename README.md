# Artist First — anteprima statica

Copia statica del nuovo sito **Artist First** (tema WordPress custom), pubblicata con GitHub Pages per la revisione del cliente.

- **Italiano:** https://ernesto-pro.github.io/artistfirst-preview/
- **English:** https://ernesto-pro.github.io/artistfirst-preview/en/

## Cosa contiene

- Home con palco 3D, calendario live, roster, uscite, playlist, news e feed Instagram.
- Archivio concerti e roster con filtri, ricerca, ordinamento e viste griglia/lista (server-side + progressive enhancement).
- Schede artista complete (discografia, video, date, gallery, link social).
- Pagine Contatti, Invia la tua musica, News, Instagram, Privacy e Cookie Policy.
- Tutte le pagine in italiano e inglese, con URL, canonical e hreflang coerenti.

## Note

Questa è un'anteprima di **design e contenuti**. Moduli, biglietteria e dati live sono disattivati: nella versione WordPress reale sono collegati ai servizi dell'agenzia.

Immagini ottimizzate in WebP con varianti responsive, CSS e JavaScript minificati, palco 3D caricato on demand.
